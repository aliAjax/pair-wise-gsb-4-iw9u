# 声线练习室（Pronunciation Lab）

纯前端英语跟读练习应用：句子库、跟读录音、掌握状态与练习进度都保存在本机（localStorage），不上传任何数据。

## 课程包更新与旧数据接管

老师更新整套练习句后，通过「导入课程包」覆盖时，不再清空学员原有的录音和进度。流程分三步：

1. **粘贴课程包**：选择老师下发的 `.json` 文件或直接粘贴，仅在本机解析，未确认前不动任何数据。
2. **核对接管清单**：自动标出四类变化并逐句展示——
   - **原句保留**：句子文字未变（译文、分类、难度等资料可更新），录音、掌握状态、练习次数原样跟随；
   - **疑似改字**：新旧文字高度相似但不完全一致，需逐个决定——
     - *改过字（默认）*：旧句连同录音与进度留档到历史区，按新文字建立全新练习项；
     - *其实是同一句*：数据跟随到新文字，不产生历史稿；
     - *新旧并存*：新句独立开练，旧句作为“留存稿”保存在历史区；
   - **新增练习句**：从新开始；
   - **被移走的句子**：自动收进历史区。
3. **确认保存**：勾选确认后才写入新课程；历史区支持恢复（录音与掌握状态保持原样）和彻底删除。手动删除句子同样先进历史区。

文字比对会归一化大小写、弯/直引号、标点和空白，避免伪改字。

## 课程包格式

```json
{
  "name": "日常英语精练",
  "version": "2026 秋 v2",
  "updatedAt": "2026-09-26",
  "sentences": [
    { "text": "The morning light feels different today.", "translation": "……", "tag": "日常", "level": "入门" }
  ]
}
```

也支持直接传句子数组。`level` 可取「入门 / 进阶 / 挑战」。

## 代码结构（资料、规则、页面各自整理）

- `src/lib/coursePack.ts` — 课程包资料：JSON 解析、校验、文字归一化、示例包；
- `src/lib/takeover.ts` — 接管规则：新旧课程比对、相似度配对、逐句决定与执行、历史归档；
- `src/components/ImportDialog.tsx` — 导入操作页面：粘贴 → 核对 → 确认三步向导；
- `src/components/HistoryView.tsx` — 历史区页面；
- `src/App.tsx` — 练习库与录音界面，数据持久化（键 `sound-lab-phrases-v2` / `sound-lab-archives-v2`，并自动迁移旧版 `sound-lab-phrases` 数据）。
